新增一个 Agent 改一行配置即可，不用改代码

[[agent]]                      # agents.toml —— 内置一份，也可放在用户目录覆盖
id      = "codex"
name    = "Codex CLI"
kind    = "cli"                # cli | electron | custom
paths   = ["~/.codex"]         # 支持 ~ / %APPDATA% / %LOCALAPPDATA% 变量
process = ["codex*"]           # 迁移前要退出的进程（可留空）
skip    = ["**/node_modules"]  # 可选：这些不加校验、直接跳过
detect  = """
  存在 ~/.codex 目录，或 %LOCALAPPDATA%/@openai-codex-updater 存在
"""
检测/迁移/回滚逻辑与具体 Agent 完全解耦：核心只认「一个或多个数据目录 + 一条进程规则」， 加新 Agent 只加配置。WorkBuddy 的实现来自已跑通的 wb-switch 迁移模块。
